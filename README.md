# market-intelligence-analytics

Parte do **Market Intelligence Ecosystem** · Produto de dados: *Flight Intelligence Platform*.

## Papel neste ecossistema
Camada de **transformação**: transformar o dado bruto de voo em **indicadores de confiabilidade** por rota e companhia, com histórico.

## Contratos
- **Entrada:** dataset bruto de voo — contrato **C1**.
- **Saída:** indicadores de confiabilidade — contrato **C2**.

Contratos, princípios e governança vivem no repositório de governança:
https://github.com/FranciscoPedro06/Market-Intelligence-Ecosystem
